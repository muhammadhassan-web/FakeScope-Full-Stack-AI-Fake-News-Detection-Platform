Developers

HTTP API

JSON endpoints for health checks and predictions. Rate-limited for fair use.

GET /health

Liveness and model readiness.

curl -s http://127.0.0.1:5000/health
{
  "status": "ok",
  "model": "Logistic Regression",
  "ready": true
}

POST /predict

Score a news string. Body must be JSON with text ({{ min_length }}–{{ max_length }} chars).

curl -s -X POST http://127.0.0.1:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"text":"Federal Reserve raises interest rates amid inflation concerns reported by CPI data."}'
{
  "label": "REAL",
  "confidence": 94.2,
  "fake_prob": 5.8,
  "real_prob": 94.2,
  "cleaned_tokens": 12,
  "model": "Logistic Regression",
  "verdict": "Likely authentic",
  "explanation": "…"
}

POST /verify

Live fact-check: searches the web for the claim, then an LLM reasons over the retrieved sources and returns a cited verdict. Returns 503 if TAVILY_API_KEY/GROQ_API_KEY aren't configured on the server.

curl -s -X POST http://127.0.0.1:5000/verify \
  -H "Content-Type: application/json" \
  -d '{"text":"NASA confirmed a new Earth-sized exoplanet this week."}'
{
  "claim": "NASA confirmed a new Earth-sized exoplanet this week.",
  "verdict": "UNVERIFIED",
  "confidence": 20,
  "explanation": "…",
  "sources": [
    {"index": 1, "title": "…", "url": "…", "snippet": "…", "cited": true}
  ],
  "checked_at": "2026-08-13T12:00:00+00:00"
}

GET /metrics

Training metrics for all compared models.

curl -s http://127.0.0.1:5000/metrics

Errors

  • 400 — validation / invalid JSON
  • 422 — text unusable after cleaning
  • 429 — rate limit exceeded
  • 502 — live fact-check upstream (search/LLM) call failed
  • 503 — model not loaded, or fact-checking not configured
